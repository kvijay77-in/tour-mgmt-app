# Management app requirements

_Last updated: 2026-09-29_

These topic files are the single source for this app's functional requirements. Backend contracts, authorization and infrastructure belong to [tour-data-api](https://github.com/kvijay77-in/tour-data-api); consult its [API reference](https://github.com/kvijay77-in/tour-data-api/blob/main/docs/design/api-reference.md) and [RBAC reference](https://github.com/kvijay77-in/tour-data-api/blob/main/docs/design/rbac.md). The shared [glossary](https://github.com/kvijay77-in/cycling-tour-platform/blob/main/docs/glossary.md) is maintained by the platform.
